# Retail Sales Analysis using SQL

## Overview

This project analyses a retail sales dataset using PostgreSQL to uncover insights into customer behaviour, sales performance, and product categories.

The project demonstrates SQL skills commonly required for Data Analyst and Business Analyst roles.

---

## Dataset

- Source: Kaggle Retail Sales Dataset
- Database: PostgreSQL
- Records: 2,000

---

## Skills Demonstrated

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- Aggregate Functions
- CASE Statements
- Common Table Expressions (CTEs)
- Window Functions
- Date Functions

---

## Business Questions Answered

- Total number of sales
- Number of unique customers
- Sales on a specific date
- Clothing sales in November
- Sales by category
- Average customer age
- High-value transactions
- Transactions by gender
- Best-performing month each year
- Top 5 customers
- Unique customers by category
- Sales by time of day
